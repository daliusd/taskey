# Minimal Taskey Eval Repo

Small TypeScript CLI fixture used by `skills/taskey/evals/evals.json` runs.

The repo intentionally has only a few files so skill evals can inspect it quickly.

## Commands

- `npm run build` — type-check the source
- `npm test` — run tests

## Existing CLI

The CLI currently supports a placeholder `list` command. Future eval prompts may ask an agent to plan commands such as `export`.
